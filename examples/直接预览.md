# Markdown 直接预览

这份文档通过对话里的路径直接打开。

## 使用方式

按住 **Ctrl** 点击 agent 回答中的 `.md` 路径，即可在旁边阅读，
不需要先进入文件浏览器。

| 路径形式 | 解析方式 |
| --- | --- |
| 绝对路径 | 打开指定文件 |
| 相对路径 | 按输出该路径的终端工作目录解析 |
| 同项目的另一个 Markdown | 复用当前预览 |

## 预览操作

- `v`：切换渲染与源码视图。
- `z`：展开或隐藏文件树。
- `/`：搜索当前文档。
- `q` / `Esc`：返回或退出。

```python
print("文件已经直接打开")
```
