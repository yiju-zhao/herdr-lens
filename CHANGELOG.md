# Changelog

## 0.1.0 — 2026-10-20

- Preview absolute and source-relative paths from agent terminals; reuse a dedicated pane.
- Render Markdown, source code, JSON and directory listings; open HTML/PDF/images externally.
- Optional Herdr File Viewer derivative opens Markdown content directly and preserves modal input.
- Optional Herdr 0.9.3 companion adds Ctrl+click for ordinary paths, including quoted Unicode paths.
- Add marketplace installation, locked Python dependencies, verified macOS Apple Silicon binaries,
  upstream source patches, development instructions and GitHub Actions tests.
- Ordinary plugin preview supports macOS/Linux; native binaries and click companion are currently
  provided and end-to-end verified for macOS Apple Silicon only. Windows is not supported.
